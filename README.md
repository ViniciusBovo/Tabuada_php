# 🧮 Gerador de Tabuada em PHP

> Um projeto simples e direto em PHP para gerar tabuadas de forma interativa e dinâmica.

---

## 📋 Sobre o Projeto

O **Tabuada_php** é uma aplicação desenvolvida em PHP com o objetivo de calcular e exibir a tabuada de qualquer número de maneira rápida. É ideal para iniciantes que estão aprendendo lógica de programação, estruturas de repetição e manipulação de formulários web usando PHP.

---

## 🚀 Funcionalidades

- **Geração Dinâmica:** Calcula a tabuada de multiplicação para qualquer número informado.
- **Interface Simples:** Formulário intuitivo para entrada de dados.
- **Validação Básica:** Garante que o número inserido seja processado corretamente.

---

## 🛠️ Tecnologias Utilizadas

- **PHP** (Linguagem de script do lado do servidor)
- **HTML5** (Estrutura da interface)
- **CSS3** (Estilização básica, se aplicável)

---

## ⚙️ Como Executar o Projeto

Para executar este projeto localmente, você precisará ter um ambiente de desenvolvimento PHP instalado (como XAMPP, WampServer ou PHP embutido).

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/ViniciusBovo/Tabuada_php.git
   ```

2. **Inicie o servidor local do PHP na pasta do projeto:**
   ```bash
   cd Tabuada_php
   php -S localhost:8000
   ```

3. **Acesse no navegador:**
   Abra o seu navegador de preferência e acesse:
   ```text
   http://localhost:8000
   ```
